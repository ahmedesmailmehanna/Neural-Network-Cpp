Build system: CMake (see CMakeLists.txt / CMakePresets.json)

configure + build (uses the "default" preset: Ninja, Release, -O3)
cmake --preset default
cmake --build --preset default

run the usage example (built as ./build/main, contains accuracy test for model v3.1)
./build/main

run the test suite (built as ./build/test)
./build/test
# or, via CTest (catches failures by scanning stdout for "FAILED", since
# test.cpp's main() currently always returns 0 - see the NOTE in CMakeLists.txt)
ctest --preset default

build only the library, skip the example/tests
cmake --preset default -DNNCPP_BUILD_EXAMPLE=OFF -DNNCPP_BUILD_TESTS=OFF

debug build (no optimization, debug symbols)
cmake --preset debug
cmake --build --preset debug

if Ninja isn't installed, drop the generator override:
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
